# 백팀 주가 흐름 사이트

백팀 8개 섹터를 섹터별로 보는 사이트예요. 한 섹터를 고르면 기준(섹터 ETF 또는 LVMH)과 그 섹터 회사가 한 차트에 겹쳐 나와요.
고른 기간의 첫 거래일 종가를 0%로 놓고 매일 몇 % 달라졌는지 그려서, **기준과 다르게 움직이는 회사**를 찾는 도구예요. 매수·매도 추천은 하지 않아요.

---

## 1. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html`, `style.css`, `app.js` | 사이트 화면. 서버 없이 이 파일만으로 돌아가요(이런 걸 "정적 사이트"라고 해요). |
| `sectors.json` | 회사 목록 설정. 섹터 번호·이름, 기준 티커, 회사 티커·한글 이름, 회사별 비교 기준. 원본은 `백팀/README.md`와 각 섹터의 `기업목록.md`. |
| `fetch_prices.py` | 야후 파이낸스에서 모든 종목의 5년 일별 종가를 받아 `data/prices.json`에 저장하는 파이썬 스크립트. |
| `data/prices.json` | 받아 둔 종가. 사이트가 이 파일을 읽어서 그려요. |
| `data/last_run_log.txt` | 마지막으로 받은 기록. 종목마다 성공·실패가 적혀 있어요. |
| `.github/workflows/update.yml` | GitHub에 "매일 이 시간에 스크립트를 돌려라"라고 알려 주는 설정 파일. |

## 2. 매일 업데이트는 이렇게 돌아요

1. 매일 **한국 시간 07:30**(미국 장 마감 뒤)에 GitHub Actions가 깨어나요.
   GitHub Actions = GitHub가 정해진 시간에 내 대신 컴퓨터 하나를 빌려 스크립트를 돌려 주는 무료 기능이에요.
2. `fetch_prices.py`가 종목마다 야후에서 5년치 종가를 받아요. 아직 장이 끝나지 않은 날의 값(장중 값)은 버리고, 마감된 종가만 써요.
3. 받은 데이터를 `data/` 폴더에 저장(커밋)해요. 커밋 = 바뀐 파일을 기록으로 남기는 것.
4. GitHub Pages가 바뀐 사이트를 다시 띄워요. GitHub Pages = GitHub 저장소의 파일을 무료 웹사이트로 보여 주는 기능.

- GitHub 사정으로 몇 분~수십 분 늦게 돌 수 있어요.
- 바로 돌리고 싶으면: 저장소 → **Actions** 탭 → 왼쪽 **주가 업데이트** → 오른쪽 **Run workflow** 버튼.
- 저장소에 60일 동안 아무 변화가 없으면 GitHub가 자동 작업을 멈출 수 있어요. 매일 데이터 커밋이 생기니 보통은 괜찮지만, 멈췄다는 메일이 오면 Actions 탭에서 **Enable workflow**를 누르면 돼요.

## 3. 처음 공개하기 (직접 할 일)

1. **GitHub 계정 만들기**: https://github.com/signup → 이메일, 비밀번호, 사용자 이름(아이디) 입력 → 이메일로 온 숫자 입력. 무료 플랜이면 충분해요.
2. **저장소 만들기**: 로그인 → 오른쪽 위 **+** → **New repository**
   - Repository name: `baekteam` (원하는 영어 이름)
   - **Public** 선택 (무료 계정의 GitHub Pages는 Public이어야 해요. 아래 4번 참고)
   - 아래 체크박스(README 추가 등)는 **아무것도 체크하지 않기** → **Create repository**
3. **파일 올리기**: 만든 저장소 주소(예: `https://github.com/아이디/baekteam`)를 Claude에게 알려 주고 "올려 줘"라고 하면 Claude가 올려요. 처음 한 번은 브라우저 창이 떠서 GitHub 로그인을 허락하라고 해요 → **Authorize** 누르기.
   - 직접 올리고 싶으면: 저장소 화면의 **uploading an existing file** 링크 → `주가사이트` 폴더 안의 파일과 폴더(`.github` 폴더 포함)를 전부 끌어다 놓기 → **Commit changes**.
   - 처음 올린 직후 Actions 탭에 빨간 X가 하나 생길 수 있어요. 아직 4단계를 안 해서 그래요. 정상이에요.
4. **Pages 켜기**: 저장소 → **Settings** → 왼쪽 **Pages** → Build and deployment의 **Source**를 **GitHub Actions**로 바꾸기.
5. **첫 실행**: **Actions** 탭 → **주가 업데이트** → **Run workflow** → 초록 버튼 **Run workflow**. 2~3분 뒤 초록 체크가 뜨면 끝.
6. **사이트 주소**: `https://아이디.github.io/baekteam/` (Settings → Pages 맨 위에도 나와요). 폰 홈 화면에 추가해 두면 앱처럼 열려요.

## 4. 공개 범위 (꼭 읽어 주세요)

- GitHub Pages 주소는 **주소를 아는 사람은 누구나 볼 수 있어요.** 로그인이 필요 없어요.
- 무료 계정은 저장소도 Public이라, GitHub에서 파일(회사 목록·코드·받은 주가)도 누구나 볼 수 있어요.
- 사이트에 검색엔진 등록 거부 표시(noindex)를 넣어 두었어요. 구글 검색에는 잘 안 나오지만, 주소를 알면 볼 수 있어요.
- 들어 있는 건 공개된 주가와 회사 목록뿐이고, 개인정보는 없어요.

**숨기고 싶다면 (쉬운 순서)**
1. **내 컴퓨터에서만 보기** (무료, 아래 7번): 공개 주소 자체가 없어요. 대신 아침에 컴퓨터가 켜져 있어야 업데이트돼요.
2. **Cloudflare Pages + Cloudflare Access** (무료, 50명까지): 사이트를 열 때 내 이메일로 온 코드를 넣어야 보이게 할 수 있어요. 설정이 몇 단계 더 있어서 원하면 Claude에게 "로그인 걸어 줘"라고 하면 돼요.
3. GitHub Pro(유료)는 **저장소만** 비공개로 바꿀 수 있고, Pages 주소는 여전히 누구나 볼 수 있어요. 숨기는 목적이라면 추천하지 않아요.

## 5. 회사 목록 바꾸는 법

원본 `백팀/README.md`나 섹터 폴더의 `기업목록.md`를 고친 뒤, Claude에게 **"sectors.json 다시 맞춰 줘"**라고만 하면 돼요.
GitHub에 올린 상태라면 "맞춘 뒤 GitHub에도 올려 줘"까지 말하면 돼요. 새 회사의 5년치 데이터는 다음 날 아침 업데이트(또는 Run workflow)에서 받아져요.

**Claude가 맞출 때 따르는 규칙**
- 섹터 순서·번호·이름: 섹터 폴더 이름(`01_전통에너지` → `01`, `전통에너지`). 화면에서 줄인 이름: 05 `결제`, 06 `금융·자산운용`.
- 기준: 각 `기업목록.md` 제목의 "기준 ETF"(07 명품은 LVMH 주가 = `MC.PA`).
- 회사: 표에 있는 모든 회사(중첩 회사 표 포함). 티커는 야후 표기로 바꾼다.
  - 점(.)이 들어간 미국 티커는 하이픈: `BRK.B` → `BRK-B`
  - 해외 상장: 파리 `.PA`, 스위스 `.SW`, 런던 `.L`, 홍콩 `.HK` (예: 프라다 홍콩 1913 → `1913.HK`)
  - 티커가 바뀐 회사는 야후에서 실제로 받아지는 쪽을 쓴다 (예: 파이서브는 파일에 `FI`로 적혀 있지만 야후에서 받아지는 건 `FISV`).
  - 7 명품 표의 LVMH는 회사가 아니라 기준이라 회사 목록에서 뺀다.
- 회사별 비교 기준: 기본은 섹터의 첫 기준. 예외는 `백팀/README.md`·`기업목록.md`에 적힌 대로 (2026-11-10 기준: 02의 카메코 CCJ는 URA, 08의 디어·뉴트리엔·코르테바·ADM은 MOO).
- 한글 이름: 화면에 짧게 나오도록 줄인 이름 (예: 옥시덴탈 페트롤리움 → 옥시덴탈).
- 다 맞추면 `python fetch_prices.py`로 새 티커가 받아지는지 확인하고, 섹터별 회사 수가 원본과 같은지 확인한다.

## 6. 데이터가 안 받아질 때 확인할 것

화면에 **"받지 못함: 티커"** 또는 **"오늘 새로 받지 못해 이전 데이터로 표시"**가 뜨면:

1. **Actions 탭**에서 가장 최근 실행을 눌러 빨간 X인지 본다 → **주가 받기** 단계를 펼치면 종목마다 성공·실패와 이유가 나와요. 저장소의 `data/last_run_log.txt`에도 같은 기록이 있어요.
2. **한두 종목만 실패**: 티커가 바뀌었거나 상장폐지됐을 수 있어요. 브라우저에서 `https://query1.finance.yahoo.com/v8/finance/chart/티커?range=5d&interval=1d`를 열어 보세요. `"No data found"`나 404가 나오면 티커 문제예요 → 기업목록을 고치고 "sectors.json 다시 맞춰 줘".
3. **전부 실패**: 야후가 막았거나 잠깐 장애일 가능성이 커요. 이 주소는 공식 서비스가 아니라 언제든 막힐 수 있어요. 하루 기다려 보고, 계속되면 Claude에게 "주가 데이터가 안 받아져"라고 로그와 함께 알려 주세요. 전부 실패한 날은 기존 데이터를 지우지 않아요.
4. **날짜가 하루 늦음**: 야후가 일부 종목(특히 유럽)의 종가를 늦게 올리는 날이 있어요. 다음 날 아침에 채워져요.
5. **업데이트가 아예 안 돔**: Actions 탭에 "This scheduled workflow is disabled" 같은 문구가 있으면 **Enable workflow**를 누르세요.

실패한 종목은 지어내지 않아요. 이전에 받은 데이터가 있으면 그대로 두고, 없으면 차트에서 빼요.

## 7. 내 컴퓨터에서 보기 (GitHub 없이)

`index.html`을 더블클릭하면 브라우저 보안 규칙 때문에 데이터를 못 읽어요. 대신:

1. 이 폴더에서 PowerShell을 열고 `python fetch_prices.py` (데이터 받기)
2. `python -m http.server 8765` (내 컴퓨터 안에서만 쓰는 작은 서버 켜기)
3. 브라우저에서 `http://localhost:8765` 열기. 다 보면 PowerShell 창을 닫으면 돼요.

매일 아침 자동으로 받으려면 윈도우 **작업 스케줄러**에 `python fetch_prices.py`를 매일 07:30으로 등록하면 돼요. 필요하면 Claude에게 "작업 스케줄러에 등록해 줘"라고 하세요.

## 8. 숫자 읽는 법과 한계 (화면의 접는 설명과 같은 내용)

- 원래 종가 기준이라 배당은 넣지 않았어요(주식 분할은 반영).
- 유럽·홍콩 상장 회사는 현지 통화(EUR, CHF, GBP, HKD) 기준이에요. 환율 변화는 들어 있지 않아요.
- 나라마다 휴장일이 달라서 각 종목은 자기 거래일 날짜대로 그려요.
- 고른 기간보다 늦게 상장·분리된 회사(GE 버노바 2024년, 베랄토 2023년)는 첫 거래일을 0%로 놓고, 기준도 그날부터 다시 계산해 비교해요.
- 두 섹터에 나오는 회사(아마존, 애플, 월마트, 블랙스톤, 에코랩, 버크셔, 웨이스트 매니지먼트)는 섹터마다 비교하는 기준이 달라서 기준 대비 값도 달라요.
- 7일은 일별 종가 5~6개로 그려요.
